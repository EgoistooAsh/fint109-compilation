About

Hi, I'm Aleck

I'm a BS Financial Technology student at Mapúa University Makati and a Risk & Compliance intern at PayMongo. I like the technical side of fintech, so this course was a chance to build the kind of pages people use every day on their phones.

These three activities took me from structuring a page correctly to designing a full app layout that rearranges itself for every screen.

What I learned

  1. Structure first. Semantic HTML5 elements and a clean heading order make pages easier to style, read and validate.
  2. Layout with Flexbox and Grid. Grid template areas let the same HTML move into different arrangements.
  3. Mobile first. Starting with the phone layout and adding media queries for tablets and desktops keeps the CSS simpler.
  4. Images that scale cleanly. max-width, aspect-ratio, object-fit and the picture element stop images from stretching.
  5. Accessibility. Alt text, color contrast, focus outlines and skip links help everyone use the page.
  6. Quality checks. Validating with the W3C checker, relative paths and consistent file names keep a project easy to share.
