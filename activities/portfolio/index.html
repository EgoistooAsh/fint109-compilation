RegWatch

PayMongo Compliance | Python automation

Watches the BSP, SEC, AMLC, DTI, FATF and the UN Security Council sanctions list, plus business news sites. It detects new issuances, summarizes them with an on-device AI model and posts them to Slack in one thread per day.

3×runs each weekday

  1. FetchPlaywright headless Chromium or JSON APIs
  2. ExtractBeautifulSoup, one item per document
  3. DiffCompare with saved state
  4. DedupeLedger so a document alerts once
  5. SummarizeLocal LLM reads page text or PDF
  6. PostSlack thread, webhook fallback
How I solved the hard parts

Moved off the cloud

The first version ran on GitHub Actions, but Philippine government sites blocked overseas datacenter IPs. I moved it to a machine on a Philippine connection, scheduled with macOS launchd.

Kept the AI on the device

Summaries run on Ollama with qwen2.5:3b, so no regulatory document leaves the machine. It fits next to a headless browser in 8 GB of RAM.

No summary beats a wrong one

Early summaries described menus and footers. I rebuilt the extractor to isolate real article text, follow linked PDFs, and post only the title and link when clean text isn't available.

Built to fail loudly

Retries with backoff, an "all clear" heartbeat on quiet runs, and warnings that repeat until a site recovers. A new source takes a few lines of YAML.
